### 🧑‍💻 Sobre mí

- Me enfoco en **backend con Java 21 y Spring Boot**: APIs REST, seguridad con JWT, arquitectura hexagonal y microservicios.
- Trabajo bases de datos con **SQL / PostgreSQL** (modelado, normalización, JPA y JDBC) y despliego entornos con **Docker**.
- Complemento con **frontend en Angular** y JavaScript vanilla para entregar proyectos full-stack.
- Me importa la calidad: **tests unitarios y de integración** (JUnit, Mockito, Testcontainers) y CI con GitHub Actions. Actualmente también me formo en **QA**.
- Hago **mentorías** a otros compañeros en Java, JDBC y Spring Boot ([guías aquí](https://github.com/crapdev/mentorias)).
